# 权限模型（0.5.0）

全局策略提供 Host 默认值，项目策略继承全局，会话实例只保存自己的覆盖。每条具体 handler 独立授权，同一事件中的不同命令也各自管理。

| 层 | 持续范围 | 编辑入口 |
| --- | --- | --- |
| 全局 | 使用同一 permissionsDir 的 Host/profile，跨项目和新会话持久生效 | 插件设置：所有项目 |
| 项目 | 规范化 Git 根目录；子目录共享、worktree 分开；无 Git 使用工作目录 | 插件设置：当前项目 |
| 会话 | 当前运行中的会话实例；关闭重建后恢复继承 | 会话浮层弹框 |

每层有继承、允许、拒绝。按会话 → 项目 → 全局查找第一个明确规则；全部继承则查看全局默认策略，最后为待授权。局部明确允许可以覆盖父层拒绝，局部拒绝也不会被父层允许覆盖。恢复继承只删除当前层的规则。

全局默认允许只使用已确认的 hook 执行版本。打开时确认当前设置页所枚举的版本；新出现的项目 hook、新版本脚本或执行方式变化仍显示待确认。关闭时保留明确的全局、项目和会话规则。

## 身份与热重载

- 权限身份独立于列表位置和展示名称。可用 handler 的可选字符串 `id` 固定身份；未指定时由来源、事件、命令和 matcher 生成，完全相同的重复项按出现顺序区分。
- 执行版本包含命令、matcher、环境、超时、输出限制、shell、上下文限制、真实来源目标，以及可识别的直接脚本和 watchPaths 的内容。改变名称或重新排列不同项不重审；修改执行内容只使相应允许规则进入待确认。拒绝规则持续生效。
- watchPaths 为整个配置集的共享依赖，变更可能使多条 hook 一起重审。复杂 shell、间接导入或无扩展名程序仍需显式声明受监视依赖。
- 每条 hook 有自己的执行租约。重载、停用、撤销只取消该租约和对应排队任务，并丢弃该租约留下的后台或待注入输出；无关 hook 的执行与权限保留。
- 文件读取和进程启动不是文件系统原子事务，仍存在外部文件改变与启动之间的 TOCTOU 窗口。

## 原子更新与继承

持久规则位于 Host 私有 permissions/policy.json，不读取项目文件中的授权声明。管理 API 只接受 Host 已枚举的工作目录、配置版本、权限版本和 hook ID，不接受任意路径。只有交互式 Host owner 能查看或修改。

设置页保存使用观察版本和跨进程互斥写入；旧窗口、并发修改和旧配置不能覆盖更新。写入在原子替换前后复核作用域和插件生命周期，取消的更新回滚。Owner 意图审计先于授权，审计文件本身不授予权限。损坏或不可读的策略不授予任何执行权限。

会话请求只接受 sessionId、revision、id、choice；额外传入全局或项目作用域会被拒绝。会话修改不会写入持久模板。会话切换后，迟到响应不能更新新会话界面；保存失败保留错误并允许重试。

继承项在下一次检查／轮询使用最新模板。已授权实例中的明确覆盖保留；恢复继承立即采用最新模板。新允许不补跑旧事件。其他 Host 进程在下一次检查或轮询观察撤销；本 Host 在管理请求完成前更新附属实例。终止已运行的子进程取决于 shell 的取消支持。

SessionStart 一次触发后即使未授权或出错也不在以后输入中补跑；新的会话或真实的 compact 生命周期可以再次触发。普通 UserPromptSubmit 等事件继续在下一次实际事件检查最新权限。

## 异常隔离与兼容

权限拒绝、待授权、配置错误、存储错误、命令异常、解析错误和插件自身的适配异常均跳过 hook，保留原生聊天、工具和压缩流程。中间件对下游 next 最多调用一次；后置异常保留已有原生结果。会话 UI 有独立渲染边界，保存失败在弹框内显示，不卸载原生输入框。

已授权命令明确输出的 exit 2、block、continue:false 仍按各事件协议处理；这类控制决定与插件异常分别处理。用户取消和原生调用自身的错误仍由 Harness 处理。

0.4.x 目录授权仅在原 canonical cwd、整份快照和执行策略完全匹配时提供兼容许可；显式会话／项目／全局规则优先于兼容许可。它不会迁移为覆盖更多目录的规则。旧审批 API 和独立 engine 用法保持兼容；插件入口启用新模型，新会话 UI 只编辑会话实例。
